# OUTPOST · Beyond the Mission

Prototipo web de una expedición lunar. Una tripulación de cinco personas explora la Luna, administra los recursos de su base y responde a cinco imprevistos. Neil Armstrong es el robot guía de la misión.

Abre `index.html` en el navegador. El juego funciona sin instalación ni dependencias.

- Muévete con WASD, las flechas o los botones en pantalla.
- Acércate al marcador amarillo y pulsa **E** o **Interactuar**.
- Revisa el costo de cada decisión antes de elegir.
